# ⚙️ CHADASH AUTOMATION

> **"Building systems for Africa and DIYers all over the world."**

Chadash Automation is an elite embedded systems and IoT engineering entity dedicated to developing resilient, decentralized technological infrastructure optimized for deployment in resource-constrained environments, while open-sourcing modular guides for global makers.

---

## 🚀 Core Ecosystem & Architecture

The application is structured as a **Refined Engineering / Dark Terminal Developer Grid** dashboard built using Next.js App Router, combining local hardware telemetry tracking with open-source documentation hubs.

### 🛠️ Technology Stack
* **Framework:** Next.js (App Router, React Client/Server Hybrid architecture)
* **Styling & Theme:** TailwindCSS (Custom Vector Matrix dark terminal grid: `#0d1117` base, `#d97706` terracotta ochre, `#10b981` emerald status green)
* **Backend Communication:** Next.js Server Actions (`transmitPacket` packet bus routing)
* **Documentation & Guides:** Interactive online curriculum nodes with offline PDF export support via browser print drivers.
